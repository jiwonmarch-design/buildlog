# Phase 3 결과: 회원가입·로그인·닉네임 변경

## 완료한 내용

- 이메일, 비밀번호와 닉네임 회원가입 API·화면
- 이메일과 닉네임 중복 검사
- 이메일 형식, 비밀번호 8~64자, 닉네임 2~20자와 문자 규칙 검사
- 비밀번호 Argon2 해시 저장
- 데이터베이스 세션과 HttpOnly 쿠키 로그인
- 로그아웃과 현재 로그인 사용자 확인
- 로그인하지 않은 사용자의 개인 화면 접근 차단
- 자신의 닉네임 변경 API·화면
- 실패 시 이메일·닉네임 유지와 비밀번호 초기화
- React 홈, 로그인, 회원가입과 계정 설정 화면 이동

## 확인한 내용

- 백엔드 회원 기능 자동 테스트 6개
- 기존 상태 API 테스트 1개
- 프런트엔드 회원 화면 테스트 3개
- 프런트엔드 lint
- 프런트엔드 프로덕션 빌드
- SQLite3 마이그레이션 적용·되돌리기·재적용
- 실제 FastAPI 서버에서 회원가입·로그인·현재 사용자·닉네임 변경·로그아웃 흐름
- 실제 React 로그인 경로 HTTP 응답

## 확인하지 않은 내용

- Supabase 연결과 PostgreSQL 동작은 관련 학습 전이므로 확인하지 않았습니다.
- 실제 배포 환경의 보안 쿠키는 배포 단계에서 확인합니다.

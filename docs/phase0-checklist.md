# Phase 0 결과: 개발 기준과 환경 확인

## 1. 결과 요약

Phase 0 확인을 완료했습니다.

- 기획 문서의 기능 범위를 대조했습니다.
- 이미 확정된 내용을 `MVP.md`에서 아직 미정으로 표시하던 부분을 정리했습니다.
- Django 기반 기술 전제를 제거했습니다.
- 프런트엔드는 React와 TypeScript, 백엔드는 FastAPI로 확정했습니다.
- 실제 서비스 데이터베이스는 Supabase PostgreSQL로 확정했습니다.
- 자동 테스트 데이터베이스는 SQLite3로 확정했습니다.
- Supabase는 데이터베이스로만 사용하고 회원가입·로그인은 FastAPI에서 처리합니다.
- Phase 1을 시작하는 데 필요한 Python, Node.js, npm과 SQLite3를 사용할 수 있습니다.
- 아직 패키지 설치, 프로젝트 생성, 데이터베이스 생성과 Git 초기화는 하지 않았습니다.

## 4. 확정된 기술 구조

### 프런트엔드

- React
- TypeScript
- FastAPI와 HTTP API로 통신
- 화면 이동과 로그인 보호를 프런트엔드에서 처리
- 실제 권한 판단 결과는 FastAPI 응답을 따름

### 백엔드

- Python
- FastAPI
- 요청·응답 입력 검사
- 회원, 권한, 기록, 댓글, 좋아요와 신고 규칙 처리
- 비밀번호 원문을 저장하지 않고 해시만 저장

### 데이터베이스

- 실제 서비스: Supabase PostgreSQL
- 자동 테스트: SQLite3 임시 데이터베이스
- 공통 데이터 접근: SQLAlchemy
- 데이터 구조 변경: Alembic

SQLite3 테스트를 통과한 뒤 Phase 13에서 같은 Alembic 변경 내역을 Supabase PostgreSQL에 적용합니다.

### npm 사용 시 주의사항

PowerShell 실행 정책 때문에 `npm`을 입력하면 `npm.ps1`이 차단됩니다. 시스템 정책을 바꾸지 않고 아래 실행 파일을 사용합니다.

```powershell
npm.cmd
npx.cmd
```

Phase 1에서는 모든 npm 명령을 이 방식으로 실행합니다.

## 7. 화면 이동 구조

화면 경로의 세부 이름은 React 프로젝트를 만들 때 확정하되 다음 역할은 유지합니다.

| 화면 | 역할 |
| --- | --- |
| 회원가입 | 이메일, 비밀번호와 닉네임 입력 |
| 로그인 | 이메일과 비밀번호 입력 |
| 내 기록 홈 | 세 기록과 계정 설정으로 이동 |
| 계정 설정 | 자신의 닉네임 변경 |
| 공부 기록 목록 | 목록과 검색 |
| 공부 기록 작성·수정 | 같은 입력 구조 사용 |
| 공부 기록 상세 | 내용, 공개 상태, 댓글·좋아요 표시 |
| 할 일 목록 | 작성, 상태 필터와 완료 체크 |
| 오류 기록 목록 | 목록, 상태 필터와 검색 |
| 오류 기록 작성·수정 | 같은 입력 구조 사용 |
| 오류 기록 상세 | 오류 내용, 해결 방법, 댓글·좋아요 표시 |
| 공개 기록 | 세 기록의 공개 목록, 종류 필터와 검색 |
| 운영자 신고 화면 | 운영자만 신고 목록과 내용 확인 |

로그인하지 않은 사용자는 회원가입과 로그인 화면만 사용할 수 있습니다.

## 8. API 영역

FastAPI 요청 경로의 정확한 문자열은 Phase 1~3에서 정하지만 기능 영역은 다음과 같이 분리합니다.

- 상태 확인
- 회원가입·로그인·로그아웃·현재 사용자
- 닉네임 변경
- 공부 기록
- 할 일
- 오류 기록
- 공개 기록과 검색
- 댓글
- 좋아요
- 신고
- 운영자 전용 신고 조회

모든 개인 데이터 API와 공개 기록 API는 로그인 상태를 확인합니다. 수정·삭제·상태 변경 API는 추가로 작성자 권한을 확인합니다.

## 10. 환경 변수 기준

### 백엔드

| 이름 | 용도 | 비밀 여부 |
| --- | --- | --- |
| `DATABASE_URL` | Supabase PostgreSQL 연결 | 비밀 |
| `TEST_DATABASE_URL` | SQLite3 테스트 연결 | 비밀 아님 |
| `SESSION_COOKIE_NAME` | 로그인 세션 쿠키 이름 | 비밀 아님 |
| `SESSION_LIFETIME_DAYS` | 로그인 유지 기간 | 비밀 아님 |
| `COOKIE_SECURE` | HTTPS 전용 쿠키 여부 | 비밀 아님 |
| `FRONTEND_ORIGIN` | 허용할 React 주소 | 비밀 아님 |
| `ENVIRONMENT` | 개발·테스트·운영 구분 | 비밀 아님 |

### 프런트엔드

| 이름 | 용도 | 비밀 여부 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | FastAPI 주소 | 비밀 아님 |

실제 값은 `.env`에 두고 `.env.example`에는 이름과 예시 형식만 기록합니다.

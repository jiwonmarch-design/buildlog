# BuildLog 프런트엔드

React와 TypeScript로 만든 BuildLog 화면 프로젝트입니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

기본 주소는 `http://localhost:5173`입니다.

## 환경 변수

`.env.example`을 참고해 필요할 때 `.env`를 만듭니다.

```text
VITE_API_BASE_URL=http://localhost:8000
```

## 확인

```powershell
npm.cmd run lint
npm.cmd run build
```
